# Plan: Finanzas personales móviles

1. Autenticar al usuario y conservar el token mediante Capacitor Preferences.
2. Consultar resumen, cuentas, categorías y movimientos desde `/api/finanzas`.
3. Presentar balance, ingresos, gastos, movimientos recientes y cuentas en la pantalla principal.
4. Permitir crear cuentas y registrar ingresos o gastos.
5. Crear categorías iniciales si el usuario todavía no tiene categorías.
6. Ofrecer recordatorios locales relacionados con gastos y presupuestos.
7. Mantener presupuestos, reportes históricos y operaciones de edición/eliminación como trabajo futuro.
